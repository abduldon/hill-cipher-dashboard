How the Hill Cipher works

A visual guide to matrix-based encryption over modulo 26.

Back to dashboard
THE CORE IDEA

Encrypt blocks with linear algebra.

The Hill Cipher converts letters into numbers and multiplies blocks of values by a square key matrix. All arithmetic is reduced modulo 26.

01

Map letters to numbers

Assign A = 0, B = 1, continuing through Z = 25.

A 0· B 1· C 2… Z 25
02

Group into blocks

A 2×2 matrix processes two letters at a time; a 3×3 matrix processes three. Encryption pads the final block with X when necessary.

2×2 BLOCKHE → [7, 4]ᵀ3×3 BLOCKHEL → [7, 4, 11]ᵀ
03

Multiply and reduce

Multiply the key matrix by each column vector and reduce every result modulo 26.

ENCRYPT
C = K × P (mod 26)
DECRYPT
P = K⁻¹ × C (mod 26)
VALID KEY MATRICES

Choose an invertible matrix

A valid key matrix must have a determinant with a multiplicative inverse modulo 26. Equivalently, gcd(det(K), 26) must equal 1. Otherwise, decryption is not defined.

EXAMPLE 2×2 KEY
K = [ [3, 3], [2, 5] ]

det(K) = 3×5 − 3×2 = 9; gcd(9, 26) = 1, so it is invertible modulo 26.

EXAMPLE 3×3 KEY
K = [ [6, 24, 1], [13, 16, 10], [20, 17, 15] ]

This classic key matrix is also invertible modulo 26.

Advantages

  • Demonstrates matrix multiplication and modular arithmetic.
  • Transforms blocks of letters together.
  • Supports clear, step-by-step mathematical visualization.

Limitations

  • Classical Hill Cipher is vulnerable to known-plaintext attacks.
  • Only matrices invertible modulo 26 can decrypt.
  • Not suitable for modern secure communication.
Educational use only

This dashboard demonstrates a historical cipher. Do not use it to protect passwords, personal data, or confidential communications.
